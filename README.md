# Парсер вакансий с HeadHunter

Проект для поиска, фильтрации и анализа вакансий с платформы HeadHunter через официальное API.

## 📌 Функциональность

- Поиск вакансий по ключевым словам
- Фильтрация по:
  - Ключевым словам в описании
  - Диапазону зарплат
  - Опыту работы
  - Типу занятости
- Сортировка по зарплате (по убыванию)
- Возможность вывода топ-N вакансий
- Сохранение результатов в JSON-файл
- Удобный интерфейс взаимодействия через консоль
